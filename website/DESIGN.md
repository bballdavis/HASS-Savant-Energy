# Documentation design

The user chose a familiar Docusaurus reading layout and direct implementation with rendered review. This is an independent documentation identity, not a change to integration branding.

Use the platform system sans-serif throughout. The wordmark is a plain typographic title with an HA compatibility suffix. A deep green accent supports navigation and actions; light surfaces serve reading, with an equivalent dark theme. Do not import vendor logos or wordmarks.

The homepage demonstrates circuit and energy monitoring immediately with an explicitly synthetic dashboard. Installation is the primary action. Guides use the standard sidebar, page contents, short task steps, expected results, and next steps. Keep code and tabular measurement values distinct from prose.

Desktop uses a two-column introduction; mobile places the image below the introduction. No decorative animation. Preserve keyboard focus, readable contrast, reduced-motion preference, and concise image descriptions.

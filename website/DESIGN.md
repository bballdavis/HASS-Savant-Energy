# Documentation design

The user chose a familiar Docusaurus reading layout and direct implementation with rendered review. This is an independent documentation identity, not a change to integration branding.

Use the platform system sans-serif throughout. The wordmark is a plain typographic title with an HA compatibility suffix. A deep green accent supports navigation and actions; light surfaces serve reading, with an equivalent dark theme. Do not import vendor logos or wordmarks.

The homepage demonstrates circuit and energy monitoring with a real, full-width companion-card capture so the circuit tiles remain readable. Installation is the primary action. Guides use the standard sidebar, page contents, short task steps, expected results, and next steps. Keep code and tabular measurement values distinct from prose.

Desktop and mobile place the real board below the introduction. The guide shows standard and ultra-compact mobile captures at readable widths. No decorative animation. Preserve keyboard focus, readable contrast, reduced-motion preference, and concise image descriptions.

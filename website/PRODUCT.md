# Documentation product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Docusaurus Classic with TypeScript; GitHub Pages; Markdown in the repository docs directory.
## Users
Home Assistant users installing, configuring, using, or migrating the community Savant Energy integration. Developers use a separate reference path.
## Product Purpose
Replace a long README with a compact showcase and accurate, task-oriented documentation.
## Capabilities and Constraints
Current-first guides; complete Legacy instructions; generated reference from static source; real captures of the companion card and Home Assistant setup, taken without changing hardware state. The companion card is bundled from a reviewed upstream commit. Packaged integration branding and backend APIs remain unchanged.
## Brand Commitments
Plain descriptive title: Savant Energy for Home Assistant. Original system-font typography and restrained accent. No vendor marks. State that the project is independent and unaffiliated with Savant.
## Evidence on Hand
Integration source, English labels, services.yaml, current protocol documentation, historical release notes. Current screenshots come from real Home Assistant; preserve their source, crop out private browser/account context, and never capture credentials.
## Product Principles
- Help readers complete a task before explaining internals.
- Describe capabilities supported by source and firmware.
- Keep maintained prose and generated reference distinct.
